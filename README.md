# RPG Music Director

Application desktop d'aide à la maîtrise de jeu pour les parties de jeu de rôle sur table.

Permet au MJ de préparer en amont une scénarisation musicale de sa campagne — un graphe nodal d'ambiances sonores, thèmes de personnages, virgules musicales et arrière-plans contextuels — puis de la déclencher pendant la partie en quelques clics.

L'analogie qui guide la conception est celle de la **musique adaptative de jeu vidéo** (Skyrim, Hollow Knight, Disco Elysium) : plusieurs couches sonores qui se superposent, se remplacent, ou s'enchaînent automatiquement selon le contexte narratif.

## Stack

- [Tauri 2](https://v2.tauri.app/) — enveloppe desktop (Rust + WebView)
- [Svelte 5](https://svelte.dev/) + TypeScript + Vite
- Web Audio API pour la pile multi-couches et les boucles fines

## Plate-formes

Windows, macOS, Linux.
